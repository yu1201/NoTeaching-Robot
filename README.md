# NoTeaching-Robot

免示教机器人上位机项目，基于 Qt + Visual Studio 开发，当前主要集成了：

- STEP 机器人驱动
- FANUC 机器人驱动
- FANUC KAREL/TP 文件生成、发送与调用
- 机器人点动、状态监控、功能测试
- 先测后焊流程
- 相机参数、手眼矩阵、测量焊接参数编辑
