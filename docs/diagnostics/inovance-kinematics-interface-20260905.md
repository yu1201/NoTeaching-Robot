## 结论

本次只读取控制器，不下发运动、不切换模式、不上电、不申请写许可，也不修改控制器或FTP文件。
当前姿态下，汇川控制器的关节角、绝对编码器脉冲、零位、减速比、编码器位数、J5/J6耦合、机械结构参数、
活动工具、活动工件坐标系和直角位置已经闭环一致，可以作为该品牌后续固定获取方式。

- 绝对脉冲反算关节角最大误差：`0.000962 deg`
- 标准DH正解与控制器基座法兰位置误差：`0.486952 mm`
- 标准DH正解与控制器基座法兰姿态误差：`0.015731 deg`
- 程序门限：`0.01 deg / 2.0 mm / 0.1 deg`

这证明当前姿态下接口字段、单位、零位和坐标约定自洽；它不等于已经证明机器人全工作空间的实体绝对精度。

## 尚不能由本次只读接口证明的内容

1. 当前只验证一个静止姿态。全工作空间、腕部翻转区和关节限位附近仍需以后采集多姿态，只读重复闭环。
2. 接口自洽不能独立证明机械零位标定、减速器回差、结构挠度和实体绝对精度；这些需要标准量具、激光跟踪仪或已知基准点验证。
3. Tool几何可读，但通用适配层尚未返回负载质量、重心和惯量；这不影响本次坐标正解，但会影响动力学与高速运动验收。
4. 当前活动Wobj是固定工件。关联变位机的移动Wobj、外部轴脉冲单位和机械耦合仍需单独型号数据与现场闭环。
5. 手眼矩阵不是机械本体运动学接口。汇川未声明控制器手眼变量读取；本地已验证手眼矩阵和二转三精度在统一流程阶段7单独验收。
6. 不同固件若改变 `MachineParams.json` 路径或字段，程序会明确失败关闭，需要用该固件导出文件更新汇川底层解析，不能回退到其它型号参数。
