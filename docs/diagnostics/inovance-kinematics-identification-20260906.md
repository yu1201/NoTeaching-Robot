# 汇川批量只读运动学辨识结果

人工整理日期：2026-09-06

## 结论

批量接口数据能够用于本地模型优化。当前成功的候选为**等效几何 + 静态柔顺项**，不是纯刚性 DH 参数微调。
这证明本地模型可高精度复现指定控制器/工具条件下的数值计算，不证明机器人实体定位精度。

型号 `IR-R8H-206S7-D1T_01741100`，固件 `V4R25C2SPC0L27F100`；实验标识 RobotC。
地址、固件、机械参数文件 SHA-256 以及工具/工件内容在每个阶段前后核对一致。
未获取独立硬件序列号，不能只按 RobotC 或品牌标签复用模型。

## 第二轮独立数据结果

工具/工件/负载 `1/1/0`（当前现场工具和工件，显式负载号0）：

|项目|最大位置误差|说明|
|---|---:|---|
|留出区域法兰正解|0.000054075 mm|同一批输入关节角，与控制器计算结果比较|
|留出区域 TCP 正解|0.000160813 mm|包括当前工具几何与等效柔顺项|
|未见过的偏移 TCP 目标逆解验证|0.024167436 mm|本地逆解关节角交给控制器 FK，不运行机器人|
|控制器原生逆解对照|0.024167436 mm|同一偏移目标及传输精度条件|

偏移目标逆解最大姿态误差 `0.001270197 deg`，12/12 组完成。
工具/工件/负载 `0/0/0` 的留出区域正解最大误差 `0.000038183 mm`；
偏移目标逆解最大误差 `0.019320238 mm / 0.001375589 deg`，12/12 组完成。

正解参考使用已发送的三位小数关节角及控制器六位小数返回；逆解回查包含 0.001 deg 关节传输舍入。
原始 FK 样本回查出现0误差，是舍入后回到同一组关节输入，不将其作为物理精度结论。
为避免这种平凡闭环，另增加了未参与训练的偏移 TCP 目标验证。

## 尚未做的部署工作

候选 `production_enabled=false`。没有改变生产 `Data/ConfigStore.db`、当前 C++ 适配实现或 Release EXE。
报告的计算精度不自动继承到当前程序；当前程序仍使用原有模型。

补全全局逆解分支、翻腕/奇异区、限位、外部轴与连续轨迹验收；不能把本轮12组近邻逆解当作完整运动安全验证。
其他安装重力方向、工具/负载、机械参数或固件变化后，应重新验证，不能直接套用本轮模型。
