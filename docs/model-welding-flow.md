# 模型焊接流程

“模型焊接流程”与现有“预设参数”流程并列。两条流程共享机器人驱动、相机、手眼参数、
STOP、会话检查、机器人操作租约和最终焊接安全执行能力，但配置和流程编排相互独立。
模型流程不得读取或改写当前预设参数组中的单条扫描起终点。

## 坐标约定

- 模型特征、V 型槽引导和 CAD 轨迹均保持在原始模型坐标中。
- 点云扫描和拟合结果表达在当前机器人 Base 坐标中。
- 定位只求纯刚体矩阵 `T_Base_Model`：
  `P_Base = T_Base_Model * P_Model`。
- 禁止在生产定位中使用缩放、镜像或 BCPD 非刚性形变。
- V 型槽长边定义为模型粗放置坐标 `+X`，短边定义为 `+Y`，右手方向为 `+Z`。
- 工件落地姿态不是任意旋转结果：只能从原始 STEP/B-Rep 中选择位于整个模型外包络支撑极值、
  且包含足够大单个连续平面的候选面吸附到地面。多个离散小脚的面积不能累加后冒充一个大面。

## 落地大面吸附与姿态门禁

三维界面以蓝色高亮当前候选落地面。执行“吸附选中大面”时，候选面的朝内支撑方向成为
地面 `+Z`；程序还必须沿该法向把 V 型槽 `anchor` 投影到候选平面，使 V 型槽地面与工件
落地面真正重合，不能只把两者旋转为平行后留下悬空或穿地状态。

只有通过上述大面验证并完成吸附后，三维场景才显示与该支撑平面一致的实体地面；未验证或
切换候选面期间不显示可作为基准的地面。V 型槽只能在此地面内拖动，每次移动都投影回地面，
不能被抬离地面或压入地下。释放 V 型槽时，如果其锚点距离选中支撑面某个投影边角不超过
吸附阈值，就自动吸附到该边角；吸附点只取支撑面投影后的外轮廓凸角，孔、内部轮廓、
加强筋顶点和共线边点不会成为吸附目标。超出阈值时仍保留为地面内的自由位置。

完成吸附并复核后，只允许绕地面 `Z` 轴调整工件在地面内的朝向。任何会改变落地面法向的
自由 X/Y 旋转都不是可保存的工件姿态；切换落地面、移动 V 型槽或绕地面 Z 调整朝向都会使
已有基准、碰撞确认和扫描起终点示教失效，必须重新确认。

若当前模型没有合格的外包络大平面，或模板的 `+Z`/V 型槽 `anchor` 未与任一候选面在允许
公差内重合，界面必须保持“未吸附”状态：禁止勾选基准确认、禁止保存模型模板，并拒绝生产
就绪检查。保存和生产检查还会重新核验当前追溯元数据及原始 STEP，不能复用已经过期的内存
候选；人工确认不能绕过这一几何门禁。

## 配置分层

模型模板保存模型 SHA-256、单位、粗放置引导、编号特征站、站点角色和相似模板来源证明。
机器人示教记录单独保存机器人名称和控制器端点身份、相机、手眼/Tool1 指纹，以及每个站点的扫描起点、终点、
起点关节脉冲、运行速度和扫描速度。两个记录都使用稳定 UUID、修订号、严格 JSON、写后回读
和模板记录 SHA-256 绑定。模板/示教的比较写入和写后回读在同一 SQLite 事务内完成；
保存示教时还会在同一事务内见证其绑定模板未被其他进程更新。

## STEP 模型导入

模型库接受 `.step`、`.stp` 和本工程固定格式 `.ply`。STEP 通过 Open CASCADE 读取 BRep，
按文件声明单位统一转换为毫米；模型原点、坐标轴和方向保持不变，不会自动居中、换轴或缩放。
界面外显与内部计算分流：三维界面直接读取原始 STEP/B-Rep 并以实体曲面和边线显示，PLY 仅供
候选点生成、配准、采样等内部计算使用，不再把 PLY 顶点当点云显示。
外显采用通用白色背景；V 型槽、编号站和扫描方向以独立标注叠加。OCCT 为屏幕光栅显示会在
内存/GPU 中生成临时显示离散数据，但不会把它发布为外显模型文件，也不会用计算 PLY 代替源 STEP。
没有可验证长度单位、根节点转换不完整、曲面缺失、坐标非有限或超过顶点/三角形上限时，导入失败且不会发布半成品。

每个 STEP 模型在 `Data/ReferenceModels` 中保存三个关联文件：

- `<name>.source.step`：原始 CAD 文件，供三维实体外显及后续精确边线和焊缝提取。
- `<name>.ply`：特征选点、定位和其他内部几何计算使用的毫米制三角网格；模板仍绑定此文件的 SHA-256。
- `<name>.model.json`：源/PLY SHA-256、OCCT 版本、声明单位、离散参数、包围盒和网格数量。

转换先在同盘暂存、写后严格回读，最后发布 PLY 作为模型库提交点。同名模型禁止覆盖；重命名和删除会同步处理
STEP 源文件和元数据。界面在工作线程中完成转换，避免大模型解析时冻结主窗口。

开发机依赖 OCCT 7.9.3 动态库。默认从 `E:\vcpkg\installed\x64-windows` 读取，也可构建时通过
`/p:OcctRoot=...` 覆盖：

```powershell
E:\vcpkg\vcpkg.exe install "opencascade[core]:x64-windows"
```

Debug/Release 构建分别链接匹配目录并复制运行 DLL；输出目录同时包含 `licenses/opencascade/copyright`。
Open CASCADE Technology 使用 LGPL-2.1 及其附加例外，正式发布时必须保留该许可文件和使用声明。

## 机器人碰撞简模场景

机器人使用独立于工件模型库的受控总装 STEP 资产，保存于 `Data/RobotModels` 并按内容
SHA-256 校验。当前自动落地仅接受已经核验坐标约定和 J0 安装面的新时达 SA10-2000H
总装（SHA-256 `f8299f6deabc7b6f6ae799592f1f93e2366311d552bf91ac431eccec14bfcaa8`）；
其它即使包含 J0-J6，也必须先补充型号、竖直轴、安装面和面向工件方向配置，不能直接套用。
加载时只提取机器人 `J0` 至 `J6` 组件，不显示厂商 STEP 中的工作空间图、管线等辅助对象，
也不会把机器人几何合并进工件 B-Rep 或内部定位网格。

工件始终保留原始 STEP/B-Rep，用于实体外显、精确焊缝提取、扫描区域着色和后续 CAD 计算；
机器人默认不加载详细总装外形，而是显示和使用由 `J0` 至 `J6` 分别生成的静态保守 AABB
碰撞简模。默认安全余量为 30 mm；除 J0 朝安装地面的下边界保持在安装面、不向地下扩张外，
各关节包络向其它方向扩张该余量。详细机器人 B-Rep 只作为可选的外显后备，不是默认显示或
碰撞计算资产，也不会替换工件的完整 B-Rep。

碰撞简模 JSON 严格绑定受控总装 STEP 的 SHA-256 和生成参数，并包含自身完整性校验。正常启动
只读取小型资产清单和该 JSON，不打开、读取、哈希或解析约 104 MB 的机器人 STEP。只有 JSON
确实缺失时才自动迁移；已有但损坏或身份不符时关闭失败，不用重新解析掩盖问题。导入或迁移时
才在后台解析总装，核验 SA10 型号、J0-J6 语义、坐标约定、安装面和前后内容身份；简模路径只
保留组件边界和基座数据，不构建详细 B-Rep 显示块。受控 STEP、碰撞 JSON 与当前资产通过条件
切换提交；任一阶段失败都条件回滚并保留原有有效模型和当前场景显示，不发布半成品，也不覆盖
其它程序实例已完成的资产切换。

工件大面吸附并显示地面后，机器人碰撞简模以静态姿态放在工件 `-X` 侧，J0 安装面落在同一
地面上，作为场景布置和粗略碰撞范围的视觉参考。当前简模明确处于“未标定、非实时姿态”状态：
该位置不代表现场机器人 Base 与模型坐标之间已经完成标定，也不跟随控制器实时关节值运动。
要进行实际轨迹碰撞检查，还必须取得 DH 参数、实时或规划关节值、现场机器人基座变换，以及
Tool1/焊枪碰撞包络；缺少这些条件时，当前场景不能作为机器人、焊枪、工装或工件无碰撞的证明。

自动候选站只用于辅助选点，默认不具备生产资格。生产配置至少需要：

1. 三个已确认且不共线的求解站。
2. 一个不参与求解的独立验证站。
3. 每个必需站的人工扫描起点、终点和起点关节脉冲。
4. 模型文件 SHA-256 未变化。
5. 当前机器人控制器端点、相机、有效手眼参数和 Tool1 的运行指纹。
6. 人工碰撞范围检查。

## 首件和相似模型

普通新模型按三维图把指定模型位置卡入 V 型槽，V 型槽只提供粗基准。扫描起点和终点仍由
现场人工示教。程序运行时在这些固定 Base 区域扫描编号特征，拟合出特征 Base 坐标，然后用
纯刚体 SVD 求 `T_Base_Model`，并由独立验证站和局部表面距离门禁确认。

相似模型可继承已保存模板快照。继承时用来源和目标模型的粗放置坐标系修复模型坐标，并保留
同一工装下的机器人扫描路径；它不会与来源模板保持活动引用。继承前必须人工确认同工装、
同实体基准、编号扫描区域仍对应且无碰撞。映射后的所有候选站仍需逐项重新确认。通过这些检查
后，运行时可以跳过 V 型槽实物粗校准。

## 当前实现边界

当前版本已经实现并接入“先测后焊”页面：

- 模型焊接流程并行入口。
- PLY、STEP/STP 参考模型导入和身份追溯；原始 STEP/B-Rep 实体三维预览，PLY 独立用于内部计算。
- 页面默认最大化；右侧模板/示教编辑区按需显示垂直和水平滚动条，底部关闭按钮固定可见。
- 可拖动的 V 型槽实体、长/短轴显示和编号候选站。
- STEP 外包络大平面候选分析、候选面高亮和落地吸附；吸附同步投影 V 型槽 `anchor`，
  吸附后只允许绕地面 Z 调整朝向。
- 验证工件大面后显示实体地面；V 型槽只能贴地拖动，释放时在阈值内吸附到支撑面投影外轮廓凸角。
- 工件始终保留原始 STEP/B-Rep，用于实体显示、焊缝提取和扫描区域着色；不会为了机器人碰撞处理而简化。
- 独立导入已核验的 SA10-2000H 受控总装 STEP，并事务化生成绑定源 STEP SHA-256 与参数的
  `J0` 至 `J6` 静态 AABB 碰撞简模；默认安全余量 30 mm，J0 不向安装地面下扩张。
- 启动直接加载碰撞简模 JSON，不解析约 104 MB 总装 STEP；详细机器人 B-Rep 仅作可选外显后备。
- 机器人简模以静态姿态在工件 `-X` 侧落地显示，并明确标注为未标定、非实时姿态。
- 未吸附合格大面时禁用基准确认，并拒绝模型模板保存和生产就绪检查。
- 模型模板、相似继承快照和机器人示教的保存/回读。
- 只读绑定当前机器人端点，并对手眼参数与控制器 Tool1 做前后双读稳定性校验。
- 纯刚体求解、尺度/反射/共线/残差/独立验证门禁及离线矩阵验证。

当前界面不会直接启动机器人。投入自动运行前还必须完成：

1. 从现有 `ScanMoveAndCollect` 拆出不生成焊缝文件的“单定位站纯采集”接口。
2. 编号点云特征拟合和每站采集质量证明。
3. 多站扫描的整段机器人租约、STOP 和安全退回编排。
4. 模型焊缝/轨迹定义、`T_Base_Model` 轨迹转换、IK/限位检查和生产证明。
5. 基于保留的 STEP BRep 定义精确焊缝/轨迹，并把源 STEP 身份纳入未来 CAD 轨迹记录。
6. 结合 DH 参数、实时或规划关节值、现场机器人基座变换和 Tool1/焊枪包络，实现动态轨迹碰撞检查。

当前自动候选站是用于界面占位和人工选点的几何启发式，不是已完成的工件特征识别算法，
因此未经逐站人工确认不会获得生产资格。
