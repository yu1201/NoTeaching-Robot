## 子界面

### 扫描变姿态精度测试

管理调试页可独立示教基础姿态、扫描起点/终点，选择扫描相机、扫描速度和后处理方式。上坡左旋、下坡右旋角度均允许设置为 `-60~60 deg`，负数表示改为与字段名称相反的旋转方向；原有正值方向不变。选择“直线处理”并成功完成扫描后，“生成并运行直线模拟轨迹”按钮读取当前机器人最新有效的 2 mm 三维曲线：曲线 XYZ 直接作为 Tool1 TCP，姿态固定使用基础姿态。运行是机器人真实运动但始终为空跑，不起弧、不送丝、不摆动；启动前显示机器人、输入文件、速度、Tool1 和基础姿态并默认拒绝，运行后验证程序完成及收枪安全位置。模拟运行不启动相机采集。

### 测量焊接参数

当前支持：

- 从控制单元中读取机器人列表
- 切换机器人驱动
- 按位置类型分组保存扫描参数和焊接参数
- 新建、复制、删除参数组，并修改分组中文名
- 示教和保存下枪安全位、扫描起点、扫描终点、收枪安全位
- 通过“扫描参数 / 焊接参数”直角标签页切换参数类型
- 按 ini 注释分组折叠显示参数
- “焊接参数 → 焊接姿态”可设置 `收下枪安全距`（必须大于 0 mm）和 `安全位回撤方向`：自动兼容旧算法、世界 X−、X+、Y−、Y+
- `重新读取` / `保存参数`

### 相机参数

当前支持：

- 选择相机
- 读取/修改相机基础参数
- 打开手眼矩阵参数窗口

相机参数/预览页不再单独选择机器人，统一使用主界面当前机器人；主界面切换机器人后重新打开相机页，会读取对应机器人下的相机和手眼配置。

### 补偿参数

姿态补偿按低平台、上升边、高平台、下降边四个物理段分别应用。四类段统一使用焊道局部基准：界面“焊道切向补偿”对应稳定焊道切向，“焊道法向补偿”对应由测量姿态选定正反分支的焊道法向，“世界Z补偿”固定对应世界 Z；坡面焊枪 RZ 夹紧和姿态过渡不再旋转位置补偿方向。各段保持刚性平移；平台与坡面补偿不同导致端点分离时，以平移后的两段无限直线延长求交，裁掉越过交点的采样点并在缺口处按步长补点。交点高程锚定平台段，后续只校直坡面段，不再用坡面新交点重插值整个平台，因此单独修改上升边或下降边不会改变相邻平台段内部点位。

补偿预览在姿态模式下显示选中段的绿色同属性高亮、局部补偿值、世界合成向量和单向实际补偿箭头；焊道模式采用相同显示方式，但因一套参数统一作用于整条焊道，高亮焊道补偿之后的整条轨迹，并按“世界 Z / 枪反向 / 焊道方向”合成实际世界补偿向量。实时修改补偿值时只替换预览图层数据，当前旋转、缩放和平移保持不变；首次选择目录或重新读取数据时才自动适配视图，也可用“重置”按钮或双击主动恢复默认视角。

### 先测后焊

当前界面入口为：

- 预设参数
- 模型焊接流程
- 线扫处理

其中 `预设参数` 与 `模型焊接流程` 是并行的功能驱动，`线扫处理` 仍为空函数。

`模型焊接流程` 的三维场景当前支持：

- 原始 STEP/B-Rep 工件实体显示，以及落地候选大面的高亮、选择和吸附；完整工件几何同时用于
  焊缝提取、扫描区域着色和后续 CAD 功能，不因机器人碰撞显示而简化。
- 工件大面验证通过后显示实体地面；未验证大面时不显示可作为基准的地面。
- V 型槽实体只能贴地拖动，释放时在阈值内吸附到选中支撑面的投影外轮廓凸角；孔和内部结构点不参与吸附。
- 从独立受控 STEP 资产导入已核验坐标约定的新时达 SA10-2000H，并为 `J0` 至 `J6` 生成
  静态保守 AABB 碰撞简模；默认安全余量 30 mm，J0 不向安装地面下扩张。
- 碰撞简模 JSON 严格绑定受控总装 STEP SHA-256 与生成参数。启动只读小型清单和 JSON，
  不读取、哈希或解析约 104 MB 的总装 STEP；仅 JSON 缺失时才以轻量边界模式后台迁移，
  导入/迁移失败时条件回滚并保留原有效模型。
- 机器人碰撞简模静态放在工件 `-X` 侧并以 J0 安装面落地；详细机器人 B-Rep 仅作为可选外显
  后备，不是默认显示和碰撞资产。

机器人碰撞简模明确标记为“未标定、非实时姿态”，只用于场景关系和粗略碰撞范围预览。
实际轨迹碰撞还需要 DH 参数、实时或规划关节值、现场机器人基座变换以及 Tool1/焊枪包络；
缺少这些条件时，不能把当前显示作为机器人、焊枪、工装或工件之间无碰撞的证明。

“机器人模型库管理”分为“本地模型”和“服务器模型”两个标签页：

- 本地模型继续显示已经通过可信型号、STEP revision、场景适配器和 J0–J6 简模门禁的型号，并在选中时生成碰撞简模预览。
- 服务器模型由 FTP 权限或全权限账号读取；列表缩略图和右侧 480×320 大图均由原始 STEP/B-Rep 曲面生成，不使用碰撞简模方框。旧清单中的简模预览会显示“需更新原图”且不再加载，重新上传同一型号后发布新的内容寻址原图。列表还显示型号、显示名称、驱动类型、STEP 大小、简模型号和服务器清单时间，右侧保留完整 SHA-256 摘要。
- 上传和下载均使用独立的文件队列，显示当前文件、确定型字节进度、速度、预计剩余时间及每项状态，并支持取消。刷新服务器列表时，清单与预览图下载也显示相同进度。
- 服务器清单只是传输与展示记录，不会直接授予生产资格。下载的 STEP、碰撞简模和原始 STEP 缩略图完成大小与 SHA-256 校验后，仍须通过程序代码内的可信型号、适配器、STEP revision、碰撞 payload 和 J0–J6 完整性门禁，失败时不登记到本地型号库。

### 在线服务

点击入口后先使用服务器固定账号登录，账号等级和界面权限如下：

- 全权限：在线升级、上传、远程浏览/下载/删除、设备目录、服务器统计、账号管理和服务器配置。
- FTP 权限：在线升级、上传、远程浏览/下载，并可修改服务器 IP 与设备名称；服务器统计、账号管理、远程删除和新建设备目录不可见或禁用。
- 上传权限：在线升级和数据上传；远程数据、账号管理、服务器配置保持禁用。

服务器配置页不再显示 FTP 账号、密码、端口、完整升级 URL 或管理令牌，只保存一个服务器 IPv4
和设备名称。数据上传页显示当前文件、真实字节百分比、速度、预计剩余时间和待上传队列；压缩或连接
阶段保持 0% 并明确显示当前阶段，不使用循环加载动画伪装数值进度。
