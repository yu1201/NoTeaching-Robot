## 当前问题项

### 待处理

2. 相机接收模式需要现场确认默认策略
   - 临时方案为“共享端口/IP 分发”默认开启，适合多个相机使用同一个本地 UDP 端口
   - 若后续每台相机改成不同端口，可在管理页面切换为独立接收模式

   - 需要用 RobotA/RobotB 分别选择不同位置类型跑一次先测后焊，确认扫描参数、焊接参数和当前分组读取正确

4. 参数组复制/删除后的误操作提示仍需观察
   - 当前已经支持新建、复制、删除和中文名编辑
   - 后续需要现场确认删除分组、切换分组、未保存修改时的提示是否足够清楚

5. [FANUC服务更新后仍需人工重启STARTALL](https://www.notion.so/349c868d819b8118aac2e6deed0fc028)

8. [手眼矩阵读取失败时会回退默认值继续运行](https://www.notion.so/349c868d819b8148915bc359d90e343c)

### 已解决

1. 补偿界面未完成
   - 已完成补偿参数界面，支持姿态补偿和焊道补偿切换、参数读取、编辑、保存
   - 焊道补偿已补充焊道方向补偿，并接入先测后焊补偿后处理

2. 先测后焊特征提取仍沿用旧分类器的改造需求
   - 已切换为新的拐点提取链路
   - 原始点直接做特征识别，拐点之间按 2mm 扩充后再进入焊接姿态和补偿流程

3. 当前位置读取与示教器显示不一致
   - FANUC 的 `CURPOS` 只能直接拿到法兰位置
   - 只靠 `CURPOS` 读回的位置容易和示教器上的 TCP 位置不一致，因此当前改为先读 `PR[3] / PR[4]` 再用 `JOINT2POS` 反算

4. 普通子界面无法从大按钮主页返回
   - 已在统一嵌入页入口增加右上角“返回主页”按钮
   - 返回时仍走子界面 `close()`，保留未保存修改和运动中禁止关闭等拦截

5. 相机参数/预览页重复选择机器人
   - 已取消相机页独立机器人选择
   - 相机页改为直接使用主界面当前机器人，并在主界面切换机器人后重新加载对应配置
