激光传感器 · FANUC 数学宏

安装与使用说明书
适用宏：AIH_CZ 垂足 / AIH_YC 延长线 / AIH_JD 交点 / AIH_YX 圆心 / AIH_YH 用户坐标系　|　控制器版本：V9.40-1　|　版本 v1.0　2026-06

1. 概述

本套宏在 FANUC 示教器上对“激光寻位得到的点（存于 PR 寄存器）”做几何计算，输出结果点到指定 PR、成功标志到指定 R。每个宏 = 一个 TP 外壳（把宏实参 AR[] 抄进 R[]）+ 一个 KAREL 内核（真正算几何）。所有角度为度，长度为 mm；姿态遵循 FANUC R = Rz·Ry·Rx。

2. 交付物清单

位于 SDK\FANUC\laser_macros\compiled\：

文件类型说明
AIH_CZ_K.pc AIH_YC_K.pc AIH_JD_K.pc AIH_YX_K.pc AIH_YH_K.pcKAREL 已编译几何内核，必须装入（控制器不编 KAREL）
AIH_CZ.tp AIH_YC.tp AIH_JD.tp AIH_YX.tp AIH_YH.tpTP 外壳已编译把 AR[] 抄进 R[] 再 CALL 内核，直接装入
AIH_*.lsTP 源码（备查）改寄存器号、或想在示教器手打时看它
全部 10 个程序（5×.tp + 5×.pc）均用现场 WinOLPC（ktrans/maketp，V9.40-1，与上位机 FanucCompileKlToPc/FanucCompileLsToTp 同一套工具）编译通过，可直接装入。

3. 调用链路（先看懂这张图）

参数填的是“寄存器编号”，不是坐标值。例：垂足(1,2,3,1,4,100) = 用 PR[1..3] 三点、姿态用 PR[1]、垂足存 PR[4]、成功标志写 R[100]。

4. 安装步骤

  1. 拷文件：U 盘把 compiled\ 里 5 个 .pc + 5 个 .tp 拷入控制器。
  2. 装 KAREL 内核：MENU → FILE → 选 U 盘设备 → 选 AIH_*_K.pc → LOAD。装完 SELECT 列表应见 AIH_CZ_K … AIH_YH_K。
  3. 装 TP 外壳：MENU → FILE → 选 AIH_*.tp → LOAD。SELECT 列表应见 AIH_CZ AIH_YC AIH_JD AIH_YX AIH_YH。
  4. 注册成宏（依传感器手册 1–3 页）：MENU → SETUP → Macro，新增 5 条，指令名填中文，程序选对应 TP 外壳：
    指令名垂足延长线交点圆心用户坐标系
    程序AIH_CZAIH_YCAIH_JDAIH_YXAIH_YH
    只注册这 5 个 TP 外壳；AIH_*_K 内核不注册，由外壳 CALL。
  5. 先自检（见第 6 节）再投产。
两种调用方式等价：宏指令方式 垂足(1,2,3,1,4,100)（从指令栏插入）；或通用兜底 CALL AIH_CZ(1,2,3,1,4,100)。参数都进 AR[]，外壳照常工作。

5. 五个宏详解

① 垂足 AIH_CZ 点到直线投影

P3 向直线(P1,P2) 作垂线，垂足落在线上

功能：求点 P3 到直线(P1,P2) 的垂直投影点。

调用：垂足(点1, 点2, 点3, 姿态点, 垂足PR, 标志R)

例：垂足(1,2,3,1,4,100) → PR1,PR2,PR3 三点，姿态用 PR1，垂足存 PR4，标志 R100。

② 延长线 AIH_YC 沿方向外延

沿 P1→P2 方向，从 P2 再外延一段“距离”

功能：方向 = P1→P2，从 P2 沿该方向外延 距离 得到延长点。

调用：延长线(点1, 点2, 姿态点, 距离, 延长PR, 标志R)

例：延长线(1,2,1,80,3,100) → 用 PR1→PR2 方向、姿态用 PR1、外延 80mm、延长点存 PR3、标志 R100。

③ 交点 AIH_JD 两直线相交

直线(P1,P2) 与 直线(P3,P4) 的交点（可外延到角点）

功能：求两条直线的交点；3D 一般取“公垂线中点”，点共面时即精确交点。

调用：交点(点1, 点2, 点3, 点4, 姿态点, 交点PR, 标志R)

例：交点(1,2,3,4,1,5,100) → PR1,PR2 一线、PR3,PR4 一线、姿态用 PR1、交点存 PR5、标志 R100。

④ 圆心 AIH_YX 三点/四点拟合圆

求法=1 用三点(P1,P2,P3)；求法=2 用四点最小二乘

功能：拟合点所在平面后求圆心。求法=1 三点法，求法=2 四点最小二乘。

调用：圆心(点1, 点2, 点3, 点4, 姿态点, 求法, 圆心PR, 标志R)

例：圆心(1,2,3,4,1,1,5,100) → 四点 PR1..4、姿态用 PR1、求法=1（三点）、圆心存 PR5、标志 R100。

⑤ 用户坐标系 AIH_YH 建 UFRAME

原点=P1；+X=P1→P2；+Y 参考=P1→P3（求法2 用 P3→P4）

功能：用寻位点建用户坐标系。原点=P1，+X=单位(P2−P1)，+Y 参考向量按求法（1/3：P1→P3；2：P3→P4）。结果(原点+姿态)写入 PR[96]。

调用：用户坐标系(点1, 点2, 点3, 点4, 求法, 坐标系号, 标志R)

生效：调用后加一行（号写常数）：UFRAME[5]=PR[96]。

6. 装好先自检（无真机也能核对）

把“输入”手动写进对应 PR（直角坐标），调用宏，单步运行，读“输出” PR 与标志，应一致：

调用输入 PR输出（应等于）
垂足(1,2,3,1,4,100)PR1(100,200,300) PR2(300,200,300) PR3(250,260,300)PR4 = (250, 200, 300)，R100 = 1
延长线(1,2,1,80,3,100)PR1(100,100,50) PR2(100,300,50)PR3 = (100, 380, 50)，R100 = 1
交点(1,2,3,4,1,5,100)PR1(0,0,0) PR2(200,0,0) PR3(120,−50,0) PR4(120,80,0)PR5 = (120, 0, 0)，R100 = 1
圆心(1,2,3,4,1,1,5,100)PR1(210,150,0) PR2(150,210,0) PR3(90,150,0)PR5 = (150, 150, 0)，R100 = 1
用户坐标系(1,2,3,4,1,1,100)PR1(0,0,0) PR2(10,0,0) PR3(0,10,0)PR96 = (0,0,0, 姿态≈0,0,0)，R100 = 1

更全的标准答案：电脑上运行 laser_macros\gen_testsheet.py。

7. 资源占用 / 前提（安装前确认）

项要求
R[61]~R[68]传参用，现场勿占用（如冲突：改 .ls 里 R[61..] 与 .kl 里 RInt(61..) 两处一致即可）
PR[96]AIH_YH 暂存坐标系结果，现场勿占用
KAREL 选项 (R632)必须已加载（现场已有 .pc 在跑则具备）
输入寻位点 PR必须直角坐标表示，不能是关节
UTOOL / UFRAME与寻位时一致；几何在哪个坐标系取点，结果就在哪个坐标系

8. AIH_YH 用户坐标系怎么生效

AIH_YH 把算出的坐标系（原点+姿态）写在 PR[96]。要真正生效，调用后加一行（号写常数）：

用户坐标系(1,2,3,4,1,5,100)
UFRAME[5]=PR[96]

这样做是为稳妥（直接写 $MNUFRAME 涉及写保护/刷新）。装好后建议用一组真值数据核一次姿态正负。

9. 常见问题

现象处理
加载 .pc 报版本不符现场机器人软件版本 ≠ V9.40-1。把 5 个 .kl（在 laser_macros\）用现场版本的 ktrans 重编：maketp/ktrans 调用须 cwd=bin、传绝对输入输出路径、不带 /config（与上位机一致）。
调用后标志 R = 0输入点退化（两点重合/三点共线/两线平行）或输入 PR 非直角坐标——检查寻位点。
找不到 AIH_*_K内核 .pc 没装或没装全；回第 4 节第 2 步。
结果姿态不对确认“姿态点”参数填的是想继承姿态的那个 PR 号。
