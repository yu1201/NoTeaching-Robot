# 激光传感器 FANUC 数学宏 —— 安装说明书

适用：AIH_CZ(垂足) / AIH_YC(延长线) / AIH_JD(交点) / AIH_YX(圆心) / AIH_YH(用户坐标系) 共 5 个数学宏。
控制器版本：编译针对 **V9.40-1**（与现场机器人版本一致；若版本不同需重编，见末节）。

---

## 一、交付物清单（在 `SDK\FANUC\laser_macros\compiled\`）

| 文件 | 类型 | 说明 |
|------|------|------|
| `AIH_CZ_K.pc` `AIH_YC_K.pc` `AIH_JD_K.pc` `AIH_YX_K.pc` `AIH_YH_K.pc` | **KAREL 已编译** | 真正算几何的内核，必须以 .pc 形式装入（控制器不编 KAREL） |
| `AIH_CZ.tp` `AIH_YC.tp` `AIH_JD.tp` `AIH_YX.tp` `AIH_YH.tp` | **TP 外壳已编译** | 把宏实参 AR[] 抄进 R[] 再 CALL 内核，直接装入 |
| `AIH_CZ.ls` `AIH_YC.ls` `AIH_JD.ls` `AIH_YX.ls` `AIH_YH.ls` | TP 外壳源码（备查） | 改寄存器号、或想在示教器手打时看它 |

> 全部 10 个程序（5×.tp + 5×.pc）都用现场这套 WinOLPC（ktrans / maketp，V9.40-1，与上位机 `FanucCompileKlToPc / FanucCompileLsToTp` 同一套工具）编译通过，**直接装入即可**。`.ls` 源码一并附上仅作备查/便于改寄存器号或在示教器手打。

## 二、安装步骤

### 1) 拷文件到控制器
U 盘把 `compiled\` 里 **5 个 .pc + 5 个 .tp** 拷到机器人，插入控制器。（`.ls` 可不拷，仅备查）

### 2) 装 KAREL 内核（5 个 .pc）
`MENU → FILE（文件）→ 选 U 盘设备（如 UD1:）→ 选中 AIH_*_K.pc → LOAD（加载）`。
装完到 `SELECT` 程序列表能看到 `AIH_CZ_K / AIH_YC_K / AIH_JD_K / AIH_YX_K / AIH_YH_K`。

### 3) 装 TP 外壳（5 个 .tp）
`MENU → FILE → 选 AIH_*.tp → LOAD`，在 SELECT 里确认出现 `AIH_CZ / AIH_YC / AIH_JD / AIH_YX / AIH_YH`。
（备选：若要改寄存器号，改 `.ls` 后用现场 WinOLPC 重编，或照第三节在示教器手打。）

### 4) 注册成宏（依传感器手册 1–3 页）
`MENU → SETUP（设置）→ Macro（宏）`：新增 5 条，指令名填中文，程序选对应 TP 外壳：

| 指令名 | 程序 |
|--------|------|
| 垂足 | AIH_CZ |
| 延长线 | AIH_YC |
| 交点 | AIH_JD |
| 圆心 | AIH_YX |
| 用户坐标系 | AIH_YH |

> 只注册这 5 个 TP 外壳；`AIH_*_K` 内核不注册，由外壳 CALL。

## 四、调用格式速查（参数都填“寄存器编号”）

```
垂足        AIH_CZ(点1, 点2, 点3, 姿态点, 垂足PR, 标志R)
延长线      AIH_YC(点1, 点2, 姿态点, 距离, 延长PR, 标志R)
交点        AIH_JD(点1, 点2, 点3, 点4, 姿态点, 交点PR, 标志R)
圆心        AIH_YX(点1, 点2, 点3, 点4, 姿态点, 求法, 圆心PR, 标志R)   求法:1=三点 2=四点
用户坐标系  AIH_YH(点1, 点2, 点3, 点4, 求法, 坐标系号, 标志R)        求法:1/2/3
```
- 结果点的**位置**=计算所得；**姿态(wpr)**=“姿态点”那个 PR 原样拷贝；`R[标志]`：1=成功 0=失败。
- 例：`垂足(1,2,3,1,4,100)` = 用 PR[1..3] 三点、PR[1] 的姿态，垂足存 PR[4]，成功标志写 R[100]。

## 五、装好先自检（务必，无真机也能核对）

把下面“入”手动写进对应 PR（直角坐标），调用宏，读“出” PR 和标志，应一致：

```
垂足(1,2,3,1,4,100):   PR1(100,200,300) PR2(300,200,300) PR3(250,260,300)
   → PR4 =(250,200,300)，R100=1
延长线(1,2,1,80,3,100): PR1(100,100,50)  PR2(100,300,50)   (距离=80)
   → PR3 =(100,380,50)，R100=1
交点(1,2,3,4,1,5,100): PR1(0,0,0) PR2(200,0,0) PR3(120,-50,0) PR4(120,80,0)
   → PR5 =(120,0,0)，R100=1
圆心(1,2,3,4,1,1,5,100): PR1(210,150,0) PR2(150,210,0) PR3(90,150,0)   (求法=1)
   → PR5 =(150,150,0)，R100=1
用户坐标系(1,2,3,4,1,1,100): PR1(0,0,0) PR2(10,0,0) PR3(0,10,0)   (求法=1)
   → PR96 =(0,0,0, 姿态≈0,0,0)，R100=1
```
> 更全的标准答案：运行 `laser_macros\gen_testsheet.py`（电脑上 `python gen_testsheet.py`）。

## 六、资源占用 / 前提（安装前确认，避免冲突）

| 项 | 要求 |
|----|------|
| **R[61]~R[68]** | 传参用，现场勿占用（如冲突：改 .ls 里 `R[61..]` 与 .kl 里 `RInt(61..)` 两处一致即可） |
| **PR[96]** | AIH_YH 暂存坐标系结果，现场勿占用 |
| KAREL 选项(R632) | 必须已加载（现场已有 .pc 在跑则具备） |
| 输入寻位点 PR | 必须**直角坐标**表示，不能是关节 |
| UTOOL/UFRAME | 与寻位时一致；几何在哪个坐标系取点，结果就在哪个坐标系 |

## 七、AIH_YH 用户坐标系：怎么让它生效

AIH_YH 把算出的坐标系写在 **PR[96]**（原点+姿态）。要真正生效，调用后加一行（号写常数）：
```
用户坐标系(1,2,3,4,1,5,100)
UFRAME[5]=PR[96]
```
> 这样做是为稳妥（直接写 `$MNUFRAME` 涉及写保护/刷新）。装好后建议用一组真值数据核一次姿态正负。

## 八、常见问题

- **加载 .pc 报版本不符**：现场机器人软件版本 ≠ V9.40-1。把 5 个 .kl 源码（在 `laser_macros\`）用现场版本的 ktrans 重编一遍即可（编译命令与本项目编 `FanucServiceLib.pc` 相同）。
- **调用宏后标志 R=0**：输入点退化（两点重合/三点共线/两线平行）或输入 PR 非直角坐标——检查寻位点。
- **找不到 AIH_*_K**：内核 .pc 没装或没装全；回到第二节第 2 步。
- **结果姿态不对**：确认“姿态点”参数填的是你想继承姿态的那个 PR 号。
