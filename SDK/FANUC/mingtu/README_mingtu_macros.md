# 明图激光传感器 FANUC 数学宏 —— 实现与测试

> 依据《明图激光传感器使用手册-FANUC(高级-客户版本)》实现的 5 个数学宏。
> MT_SEARCH / MT_SUB_WELD（涉及 SENSOR SEARCH / 多层焊指令）未含在本批，后续单独做。

## 1. 架构：TP 外壳 + KAREL 内核

标准 TP 无法做开方/三角/解方程，因此沿用本项目既有模式（参见 `FANUC_JOGJ.ls` → `CALL LOADJOGBUF`）：

```
操作员在焊接程序里调用宏  ──►  MT_xx.ls (TP 外壳)
                                  把宏实参 AR[1..n] 抄进 R[61..]
                                  CALL MT_xx_K
                                       └──►  MT_xx_K.kl (KAREL 内核)
                                             读 R[61..] 取 PR/参数 → 计算
                                             → SET_POS_REG(结果PR) + SET_INT_REG(标志R)
```

- **位置**用结果 PR 输出；**姿态(wpr)+config** 一律拷贝自“姿态点”那个 PR（手册：使用点N的姿态）。
- **标志 R**：`1`=成功，`0`=失败（退化：两点重合 / 三点共线 / 两线平行）。

## 2. 寄存器握手约定（可改）

参数传递统一用 `R[61..68]`，KAREL 内部临时量自带局部变量，不占用 R。
**若与现场已用寄存器冲突，改 `.ls` 里的 `R[61..]` 和 `.kl` 里 `RInt(61..)` 两处保持一致即可。**

| 宏 | 调用形式（实参=寄存器编号） | AR→R 映射 |
|----|------------------------------|-----------|
| **MT_CZ** 垂足 | `MT_CZ(P1,P2,P3,姿态,垂足PR,标志)` | R61=P1 R62=P2 R63=P3 R64=姿态 R65=垂足 R66=标志 |
| **MT_YC** 延长 | `MT_YC(P1,P2,姿态,距离,延长PR,标志)` | R61=P1 R62=P2 R63=姿态 R64=距离 R65=延长 R66=标志 |
| **MT_JD** 交点 | `MT_JD(P1,P2,P3,P4,姿态,交点PR,标志)` | R61=P1 R62=P2 R63=P3 R64=P4 R65=姿态 R66=交点 R67=标志 |
| **MT_YX** 圆心 | `MT_YX(P1,P2,P3,P4,姿态,求法,圆心PR,标志)` | R61..R64=P1..P4 R65=姿态 R66=求法 R67=圆心 R68=标志 |
| **MT_YH** 坐标系 | `MT_YH(P1,P2,P3,P4,求法,坐标系号,标志)` | R61..R64=P1..P4 R65=求法 R66=坐标系号 R67=标志 |

> 例：`MT_CZ(1,2,3,1,4,100)` = 用 PR[1..3] 当三点、PR[1] 的姿态、结果写 PR[4]、成功标志写 R[100]。

## 3. 各宏的数学与默认约定

| 宏 | 计算 | ⚠ 需现场确认的约定 |
|----|------|--------------------|
| MT_CZ | `foot = P1 + ((P3-P1)·u/|u|²)·u`, `u=P2-P1` | 无（唯一解） |
| MT_YC | `ext = P2 + 距离·unit(P2-P1)` | ✅ 与手册图/示例一致：延长点在 P2 外侧，距离=超出 P2 的量 |
| MT_JD | 两线最近点中点（公垂线中点） | ✅ 与手册图一致：两线交点；点共面时公垂线中点=精确交点，兼容噪声/轻微异面 |
| MT_YX | 平面拟合→2D 代数圆拟合(Kåsa)→回映；求法1取前3点、求法2取4点最小二乘 | 4 点拟合算法若厂商不同，圆心略有差异 |
| MT_YH | 原点=P1；+X=unit(P2-P1)；+Y 参考=（求法2:P3→P4，否则 P1→P3）；ez=unit(ex×ref)，ey=ez×ex；wpr 按 `R=Rz·Ry·Rx` 反解。**结果(原点+姿态)写入 PR[96]** | ✅ 点→轴映射已按手册三张示意图确认(求法1/3:Y参考=P1→P3；求法2:Y参考=P3→P4；原点均=P1、+X=P1→P2)；建议用真值数据核一次姿态符号。坐标系应用：`UFRAME[<号>]=PR[96]`(号为常数)；自动写 `$MNUFRAME` 待控制器确认 |

姿态/角度遵循 FANUC：`W绕X P绕Y R绕Z`，`R = Rz(R)·Ry(P)·Rx(W)`（与本项目 `CLAUDE.md` 一致）。

## 5. 在示教器上导入并注册为宏（依手册 1~3 页）

1. U 盘把 `MT_*.tp`（由 `.ls` 编译）和 `MT_*_K.pc`（由 `.kl` 编译）拷入机器人；`选择程序界面-F1-TP 程序` 确认导入。
2. `MENU-设置(SETUP)-宏(Macro)`：新增一条，指令名称填中文（如“垂足”），程序选 `MT_CZ`，分配到指令/手动键。
3. 编程时在指令栏选对应宏，填入寄存器编号实参即可。

## 6. 没有机器人时怎么测（四层）

| 层 | 做什么 | 工具 |
|----|--------|------|
| ① 数学 | `python oracle.py` 自检 6/6；`gen_testsheet.py` 出标准答案 | 已就绪 |
| ② 编译 | `ktrans MT_CZ_K.kl`（KAREL→.pc）、`maketp MT_CZ.ls`（TP→.tp），查语法 | WinOLPC（随 ROBOGUIDE） |
| ③ 运行 | ROBOGUIDE 虚拟控制器：用 PR 写入第4节“入”，运行宏，读回结果 PR/标志，对标准答案 | ROBOGUIDE |
| ④ 自动 | 用本项目 `FanucServiceLib.kl` 的 `SET_POS_VAR/GET_POS_VAR` socket 命令连虚拟控制器：脚本灌入 PR→跑宏→读 PR→与 `oracle.py` 逐点对拍 | 纯软件 |

> ② 的编译检查最关键也最快：能立刻抓出 KAREL/TP 语法错误，不需要机器人，也不需要 ROBOGUIDE 跑仿真。
